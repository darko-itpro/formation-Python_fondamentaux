# Fichiers et système de fichiers

Dans ce projet, le répertoire `/assets` contient des ficheirs texte avec lesquels vous allez 
pouvoir travailler.

## Le contenu d'un répertoire

Écrivez une fonction qui retourne le contenu du répertoire `/assets/files/`. Cette fonction ne doit 
retourner que des noms de fichiers.

Dans l'idéal, cette fonction n'est pas spécifique à ce répertoire, le répertoire est attendu comme
paramètre.

## Le contenu d'un fichier

Nous allons travailler sur le fichier `/assets/showslist.csv`. Dans ce fichier, chaque ligne 
représente un épisode avec les informations : nom de la série, numéro de saison, numéro d'épisode, 
titre, durée, année.

 * Ouvrez le fichier, parcourez le et retournez le contenu où chaque ligne est une liste des données 
du csv.
 * Utilisez ce retour pour créer des séries et les alimenter en utilisant les classes de la 
   médiathèque.
