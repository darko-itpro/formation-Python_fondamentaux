15  Les expressions rationnelles

Les expressions rationnelles, expressions régulières (anglicisme de Regular Expressions) ou simplement RegEx sont un puissant moyen pour rechercher ou isoler une chaine de caractères. Elles permettent la recherche d’un motif ou la validation d’une chaine de caractères.

Utiliser les regex consiste avant tout à définir un motif décrivant la chaine de caractères recherchée. C’est la partie la plus complexe. Ce document n’est qu’une introduction à la définition de ces motifs.

En Python, les expression rationnelles sont gérées par le module re

15.1 Définir un motif

Utiliser les RegEx consiste avant tout à définir un motif décrivant la chaine de caractères à rechercher ou valider. Ce motif est lui-même une chaine de caractères. Le moteur de RegEx cherchera à identifier ce motif dans une chaine de caractères.

La suite de ce document présente une introduction à la définition d’un motif. La documentation citée en référence est bien plus exhaustive.

15.1.1 Un motif de base

Le motif le plus simple est une chaine de caractères strict. ‘chat’ par exemple peut être sera identifié dans la chaine de caractères ‘chat’ mais aussi ‘chaton’, ‘achat’ et ‘un chat noir’.

15.1.2 La position d’un motif

Le symbol ^ en premier caractère est un marqueur indiquant que le motif doit être en début de chaine. Ainsi, '^chat' identifie la chaine 'chat’ dans les chaines de caractères 'chat' et 'chaton' mais pas dans 'achat' ni dans 'un chat noir'.

De même, le symbol $ en dernier caractère est un marqueur indiquant que le motif doit être en fin de chaine. Ainsi, 'chat$' identifie la chaine 'chat' dans les chaines de caractères 'chat' et 'achat' mais pas dans 'chaton' ni dans 'un chat noir'.

15.1.3 Les classes de caractères

Les crochets permettent de définir quel caractère sera attendu parmi ceux entre crochet à l’emplacement des crochets. Dans les crochets, les caractères - et ^ ont un comportement spécial décrit ci-dessous.

  • [aeiouy] signifie un caractère parmi ceux entre crochets
  • [a-z] signifie un caractère entre a et z en minuscule.
  • [a-zA-Z] signifie un caractère entre a et z en minuscule ou capitale.
  • [a-z-] signifie un caractère entre a et z en minuscule ou un tiret.
  • [^aeiouy] le ^ est une négation, ici, il est attendu n’importe quel caractère sauf un de ceux entre crochets.
  • . signifie n’importe quel caractère.

Les crochets signifient donc ou.

15.1.4 Nombre d’occurrences

Un caractère ou une classe de caractères peut être attendu plusieurs fois. La définition d’un motif permet donc d’indiquer combien de fois un caractère est attendu en fonction du symbole suivant placé après :

  • * : 0, 1 ou plusieurs occurrences
  • + : 1 ou plusieurs occurrences
  • ? : 0 ou 1 occurrences
  • {m} : strictement m occurrences
  • {m,n} : entre m et n occurrences
  • {,n} : de 0 à n occurrences
  • {m,} : plus de m occurrences

15.1.5 Les groupes de caractères

Les parenthèses permettent de définir des groupes de caractères qui sont attendus dans leur ensemble. Les parenthèses définissent une relation et.

Un groupe peut être combiné à d’autres marqueurs : * (chat)+ est présent dans 'chatchat' (deux fois) et dans 'tchatchatcha' (deux fois aussi). * ([rf]i)+ identifie 'riri' et 'fifi' (et 'firi' ou 'rifi' ou 'rifiri'…) * (M.|Mme) identifie soit 'M.' soit 'Mme'.

15.1.6 Référence précédente

À l’aide d’un metacaractère appelé backreference, nous pouvons matcher un groupe capturé précédemment. Ce metacaractère s’écrit \n où n est un entier qui représente le match du nième groupe capturé.

Ce metacaractère permet d’éviter tout problème avec le pattern ([rf]i)+. Ainsi, identifier spécifiquement 'riri' ou 'fifi' mais ni 'rifi' ou 'firi', le pattern est ([rf]i)\1. En passant, pour ajouter 'loulou' aux matchs possibles, nous pouvons ajouter le ou : ([rf]i|lou)\1. ## Utiliser le module re

Pour utiliser les RegEx, Python fournit le module re.

15.1.7 Les fonctions de recherche

Le module re propose les fonctions de recherche suivantes :

  • re.search(pattern, string) recherche le motif dans la chaine
  • re.match(pattern, string) recherche le motif en début de chaine
  • re.fullmatch(pattern, string) recherche un motif exact du pattern sur la chaine.
  • re.findall(pattern, string) : retourne une liste de toutes les occurrences du motif sous forme de chaine de caractères
  • re.finditer(pattern, string) : retourne un itérateur de match objects (voir ci-dessous).

Si la fonction (à part findall) trouve une correspondance, un Match Object, est retourné sinon None.

Une RegEx peut également être utilisée comme un objet. La fonction re.compile(pattern) retourne un objet de type _sre.SRE_Pattern dédié à l’identification du motif décrit par pattern. Cet objet dispose de méthodes similaires aux fonctions précédentes.

15.2 Les Match Objects et leurs attributs

Un Match Object expose principalement les 3 méthodes suivantes. Le paramètre optionnel subgroup est un entier ou une chaine de caractères.

  • group([subgroup]) : retourne le motif trouvé (sans paramètre ou avec la valeur 0) ou le motif correspondant au sous-groupe.
  • start([subgroup]) : retourne l’indice de début du motif trouvé (sans paramètre ou avec la valeur 0) ou pour celui correspondant au sous-groupe.
  • end([subgroup]) : retourne l’indice de fin du motif trouvé (sans paramètre ou avec la valeur 0) ou pour celui correspondant au sous-groupe.

Le paramètre sous-groupe représente un des groupes définis par des parenthèses. La seconde fonction des groupes est donc de définir des sous-motifs d’intérêt. Ceux-ci permettent de définir l’information réelle que nous souhaitons obtenir lorsqu’il n’est pas possible de définir un motif pour l’information que nous recherchons.

L’exemple suivant définit un motif de recherche de nombres décimaux ayant une précision minimale de deux chiffres.

Les groupes sont utilisés pour permettent d’extraire la partie entière et la partie décimale.

import re

float_regex = re.compile('([0-9]+)\.([0-9]{2,})')

ma_chaine = 'pi vaut 3.14'

resultat = float_regex.search(ma_chaine)

if resultat:
    print(resultat.group())
    print(resultat.group(0))
    print(resultat.group(1))
    print(resultat.group(2))
   
# Affiche:     
# 3.14
# 3.14
# 3
# 14

print(resultat.start())

# affiche:
# 8

print(resultat.end())

# Affiche:
# 12

print(resultat.start(2))

# Affiche:
# 10

Remarquez le test à la ligne 5, il s’agit d’un pattern de code commun. Il est indispensable de vérifier l’existence d’un résultat afin d’appeler les méthodes sur ceux-ci et non sur la valeur None. Python nous simplifie la tâche avec le sens falsy de None.

Se retrouver dans la numérotation des groupes n’est pas toujours évident surtout qu’un motif peut définir des groupes pour extraire de l’information mais aussi pour grouper des caractères en vue de leur description.

Il est donc possible d’utiliser des marqueurs. Ainsi, un groupe avec la syntaxe suivante (?P<name>…) définira une étiquette name et c’est cette étiquette qui permettra d’identifier le groupe.

float_regex = re.compile('(?P<whole>[0-9]+)\.(?P<fraction>[0-9]{2,})')

resultat = float_regex.search(ma_chaine)

if resultat:
    print('1', resultat.group(1))
    print('whole', resultat.group('whole'))
    print('fraction', resultat.group('fraction'))
    print('start fraction', resultat.start('fraction'))

# Affiche:
# 1 3
# whole 3
# fraction 14
# start fraction 10

15.3 Les substitutions

Les RegEx peuvent être utilisées pour substituer du texte grâce à :

  • La fonction sub(pattern, repl, string, count=0, flags=0)
  • la méthode sub(repl, string, count=0, flags=0)

Les paramètres sont : * repl peut-être soit une chaine de substitution, soit un callable, c’est à dire une fonction. Celle-ci prendra en paramètre un match object et devra retourner une chaine de caractères. * count permet de limiter le nombre de substitutions.

Le code suivant illustre la substitution avec une chaine de caractères fixe.

ma_chaine = 'pi vaut 3.14 et e vaut 2.72'

float_regex.sub('quelque chose', ma_chaine)
# Retourne :
# 'pi vaut quelque chose et e vaut quelque chose'

Le code suivant illustre une substitution plus intelligente avec une fonction.

temp_pattern = r"(?P<temp>[0-9]+\.[0-9]{2})°(?P<value>c|F)"

t_regex = re.compile(temp_pattern)

def simplify(temp_match):
    temp = float(temp_match.group('temp'))
    if temp > 30:
        return "Trop chaud"
    elif temp < 15:
        return "Trop froid"
    else:
        return temp_match.group() 

t_regex.sub(simplify, r"Il fait 17.08°c")
# Retourne:
# 'Il fait 17.08°c'

t_regex.sub(simplify, r"Il fait 32.08°c")
# Retourne:
# 'Il fait Trop chaud'

t_regex.sub(simplify, r"Il fait 12.08°c")
# Retourne:
# 'Il fait Trop froid'
